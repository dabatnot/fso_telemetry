# Archive de l'ancienne certification

Ce dossier conserve l'état des spécifications et du suivi avant leur recentrage sur le produit le 31 juillet 2026.

Son contenu est historique et non normatif :

- il ne fait plus partie des spécifications actives du projet ;
- il ne définit aucun objectif, critère de livraison, gate ou procédure à exécuter ;
- il ne doit pas servir de modèle, de source d'inspiration ou de point de départ à une nouvelle spécification ;
- ses checklists, lots, matrices, budgets, campagnes et statuts ne doivent jamais être repris automatiquement ;
- aucune pièce contenue ici ne peut bloquer le développement ou la livraison.

Les spécifications actives se trouvent dans [`../../specs`](../../specs). Un agent qui consulte cette archive doit revenir à ces documents actifs avant toute décision.

Le sous-dossier `specs` contient une copie des trois anciens contrats. Le sous-dossier `progress` contient l'ancien tracker Phase 2. Ils sont conservés uniquement pour comprendre l'historique du projet.
