# Spécifications actives de télémétrie

Ce dossier contient les seules spécifications de phase actives :

- [Phase 0 — contrat de protocole](0-Contrat-de-protocole/README.md), 27 exigences ;
- [Phase 1 — squelette et premier flux](1-Squelette-et-premier-flux/README.md), 38 exigences ;
- [Phase 2 — vaisseau complet](2-Vaisseau-complet/README.md), 50 exigences ;
- [Phase 3 — ciblage et capteurs](3-Ciblage-et-capteurs/README.md), 46 exigences.

Les 161 exigences apparaissent exactement une fois dans le document
`07-livraison-et-tracabilite.md` de leur phase. Les dépendances vers une phase
antérieure sont des liens et ne créent pas une seconde exigence.

Les documents racine de [`documentation/analysis`](../README.md) fixent les
invariants communs et la terminologie. Les schémas wire et golden vectors
versionnés restent l’autorité pour les octets. Les roadmaps, exemples
prospectifs et archives sont non normatifs.
